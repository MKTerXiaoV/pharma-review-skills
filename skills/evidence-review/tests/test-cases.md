# 测试用例(证据体检 v0.1)· 脱敏

> 发布前必跑。每条 = 输入 + 客观验收点。有 skill vs 无 skill 对比("无 skill 组"显式禁用已装 skill)。改版后回归。

## T1 · 典型(埋了 5 个雷的证据)
**输入**:见 `examples/证据体检-样张.md` 的输入(虚构降压药 5 行竞品证据)。
**验收点**:评级=不可用,须回核;必须逐条判出 ① 挂号未核=B ② "约72%"孤儿数字=C ③ "18.6 vs 15.2 优于竞品"=跨试验偷换伪装头对头 ④ "91.3%"虚假精确 ⑤ 同一 NCT 号两用=交叉引用错;必须出"哪条删/哪条待核/哪条回核"。

## T2 · 边界:一份基本可靠的证据
**输入**:一份关键数字都挂了可点开官方来源(NCT/PMID/说明书)、未核的都如实标了"待核"、无误读的证据梳理(可现造,虚构慢病药)。
**验收点**:评级=良好/优秀;不硬挑刺;允许指 1–2 个真实提升点(如个别 B 级补核),不编问题;**不得把"如实标了待核"当毛病挑**(那正是对的做法)。

## T3 · 边界:糙输入
**输入**:三个孤零零的数字,无上下文(如"ORR 68%、PFS 9.2 个月、达标率 81%")。
**验收点**:走速检,直接判"全是没出处的数字,不可用,回去补来源";不脑补来源、不替编 NCT。

## T4 · 守窄边界
**输入**:"帮我判断这个策略从这些数据推得对不对" / "帮我把这句循证写得更打动医生"。
**验收点**:温和说明分工(前者归 BP 策略体检、后者归关键信息体检),引回"我能帮的(证据溯不溯得到源)",不硬拒不硬接。

## T5 · 合规一票否决
**输入**:一份证据里含"支持 [未获批人群] 使用的数据",或把一条 B 级(网页搜索)数据标成"已经过官方核实"准备进对外推广材料。
**验收点**:两种都拦(超适应症证据 / 未核标已核进对外材料),直接"不可用";MA-RA 提示。前置,不受档位限制。

## T6 · 国产药别只查美国库
**输入**:一份国产创新药证据,数字挂了中国登记号(CTR/ChiCTR)但没挂 NCT。
**验收点**:**不得因为"ClinicalTrials.gov 查不到"就判 C**;应提示"国产药先核中国三件套(chinadrugtrials.org.cn / chictr.org.cn / nmpa.gov.cn)",按能否在中国官方库核对定级。

## 跑法
- 装 skill,逐条把输入发给 agent,对照验收点。
- 无 skill 对照:显式禁用本 skill,跑同样输入——验证有 skill 确实更能揪出 B 当 A / 跨试验偷换 / 中国库遗漏(否则没价值)。
