# 迭代法 · 让证据体检越用越像你

> 体检系列通用的自我进化回路。几轮后,它挑刺越来越像你这个专家 = 别人抄不走的私域护城河。

## 回路(四步)
1. **体检真实证据**:拿一份你手头真实的证据材料(自己扒的、下属交的、AI 生成的)让它体检。
2. **你亲手改满意**:它挑的你不认同的、漏挑的、判级判错的——你自己改到满意。
3. **让 AI 提炼"你改了什么 + 背后规则"**:把你的修改喂回去,让它归纳成规则。
4. **写进 EXTEND / references**:规则沉淀下来,下次自动带上。

## 这个 skill 特别值得攒的规则
- **你所在治疗领域的"看着对其实不能用"的坑**:哪些数据来源在你这行是二手/不可信的、哪些会议摘要还不能引、哪些竞争性表述你们合规一定卡。
- **你的分级习惯**:什么情况你会把一个 B 级直接毙(而不只是待核)、什么来源你认可为 A 级。
- **国产药的库经验**:某些产品的数据到底登在哪个中国平台、哪些只有中文说明书。

## 注意
- **脱敏后再喂**:攒规则时去掉真实产品/公司/内部信息。
- 规则 ≤10 条,长了让 AI 归纳合并(防打架)。
- 攒的是"真实会溜过去的坏样子",不是稻草人——越真实越有用。
