# 洞察体检 · 市场部怎么用

> 给市场部的人看的使用介绍(不是给 skill 开发者的)。一句话:**策略往下推之前,先看看底下垫的那条洞察是不是真的。**

## 你什么时候会想起它(三个真实时刻)

1. **BP 写到「客户洞察」那一页,写完了自己也不确定。** 读着挺顺、听着挺深,但不知道它到底是洞察还是一句漂亮的常识。先体检,再往下推策略——这一页垫歪了,后面全歪。

2. **下属、agency 交来一页洞察,你要不要签字往上带。** 你签的字你负责。老板真正会问的就三句:凭什么这么判?医生是真这么做还是这么说的?这条改变了我们哪个动作?先体检,把这三句先答一遍。

3. **你用 AI 生成了一版客户洞察,看着条条有理。** 最危险的恰恰是这种——AI 特别擅长把常识写得像洞察,把背景写得像发现。先体检,再进 deck。

## 怎么用(30 秒上手)

把那句洞察、或那一页洞察整段粘进去,说一句"体检一下"。一句话也能审。
- **想快** → 告诉你这算不算洞察,以及差在哪。
- **想稳** → 逐条归筐 + 挑刺 + 告诉你哪条删、哪条降级、哪条补什么证据就能立住。
- **要进 BP / 上评审** → 再加合规逐条过 + 改前改后对比。

## 最有用的一刀:先归筐

它会把你每一条先扔进四个筐里的一个:

- **现象** = 你只说了发生了什么,还没说为什么 → 不是错,是没挖完
- **常识** = 换成任何同类产品都成立 → 删
- **金句** = 好听,但指不出是谁、在哪、做了什么 → 删,或者回去找对应的行为
- **洞察** ✅ = 解释了一个"最容易想到的解释"解释不了的选择 → 留

归完筐,判为洞察的还要再过一关:**看到什么 → 为什么 → 不管它会怎样**。三段少一段,退回"现象"。

## 它替你挡掉的祸(一页真材料举例)

一份 BP 的客户洞察页,7 条,乍看条条在理。体检完:
- "患者健康意识提升" → 常识。换成任何慢病产品都成立,删。
- "三线转化率 12%,一线 31%" → 现象。为什么呢?材料里没有。
- "主要障碍是价格和准入" → 套话。而且一线三线价格一样,解释不了那 19 个点。
- "我们要占早期干预,所以医生渴望更早识别" → 因果反了,这是我们想要的,不是他想要的。
- "12 位专家一致认为……" → 顾问会上的"一致认为"是场合的产物,降级为待验证。
- "他们要的不是处方,是安心" → 金句。指不出人、场景、动作。
- "患者问题是依从性差" → 只剩尾端。前端(来没来看、看对科没)和中间(候诊时怎么理解这个病)一个字没有。

结论:7 条里没有一条能当洞察用。**这一页要是没体检就往下推,后面的策略、信息、活动全部建在一句常识上。**

## 它不干什么(这是它的本分)

- **不替你挖洞察、不替你做调研**——那是另一回事,它只审你手里已经有的。
- **不替你拍板真假**——它只标"这条现在的证据撑不起这个判断",能不能立,你去补证据定。
- **不评策略好不好**——它只问"这条指不指得出一个具体动作",指得出就放行,策略本身归 BP 策略体检。
- 一句话:**它把最容易糊弄过去的那件事——"这句话到底是不是洞察"——摆在你面前;真要怎么办,判断还是你的。**

## 一句到位

以前是"洞察写得漂亮就过了,出事再说";现在是"往下推之前先过一道体检"。省的不是时间,是一整套建在常识上的策略、活动和预算。
