# 信源角色与场景信任梯度

> 同一句话,从谁那里、在什么场合拿到的,决定了它能当多少证据用。
> 这一维是本尺和通用洞察工具最大的差别——医生的"说"和"做"经常是两回事,而且"说"的失真程度随场合剧烈变化。

## 一、证据角色四类(按权重从高到低)

| 角色 | 典型来源 | 能回答 | 不能单独回答 |
|---|---|---|---|
| **所做** ⭐ | 真实处方与份额、换药/停药/减量、复诊率、转诊流向、门诊里实际完成了哪些动作 | 他真的怎么选 | 为什么这么选 |
| **多大** | 患者流漏斗各环节转化率、路径衰减率、渗透率、Mind Share 调研 | 这个问题有多大、在哪一环最大 | 为什么衰减 |
| **所说** | 访谈、问卷、会议发言、拜访问答、代表转述 | 他怎么描述自己的处境、用什么词 | 他是不是真这么做 |
| **所想** | 研究者的推断 | —— | 什么都不能单独回答 |

**硬规则**:
1. **「所想」必须显式标为推断**,不能和事实混写在同一句里。
2. 一条洞察的支撑**只有「所说」**时,最多到待验证假设。
3. 「所说」和「所做」打架时,**以「所做」为准**,并把这个矛盾本身当成洞察的入口——说的和做的不一致,中间那个缝隙往往就是真正的动机所在。

## 二、场景信任梯度(拿到这句话的场合)

| 场合 | 真实度 | 为什么 |
|---|---|---|
| 多专家在座的会议 / 顾问会 | **最低** | 政治正确、背指南、话是说给同行和公司听的 |
| 多人组合拜访(代表+经理+医学一起上) | 低 | 从一开始就在制造失真,回答偏乐观、偏正确 |
| 单独约见办公室 | 中 | 比公开场合真,但仍有"被拜访"的心态 |
| 非正式随行、闲聊中冷不丁问一句 | **最高** | 对方来不及进入表演模式 |
| 真实门诊/病房里的直接行为观察 | **最高** | 不经语言,直接看动作 |

**硬规则**:
- 支撑只有「所说」、且场合落在前两行 → **一律降级为待验证假设**。
- 材料里如果根本没写证据是从哪来的 → 按"来源不明"处理,同样降级,并在改法里点名"补来源"。

## 三、体检时怎么标

每条洞察后面标一行:
```
证据:[所做/多大/所说/所想] · 场景:[会议/组合拜访/单独约见/非正式/行为观察/来源不明] · 结论:[可用 / 降级为待验证假设]
```

## 四、常见翻车

- **把代表转述当医生原话**:中间隔了一层,而且代表有自己的处境。标为「所说」且降一档。
- **把一次会议的共识当普遍动机**:会议共识 = 场合产物,不是行为证据。
- **把"我们调研过"当免检**:要问调研问的是谁、在什么场合、问题是怎么问的(见黑名单第 6 条"母爱爆棚")。
- **只有顶级专家,没有中间段医生**:支撑生意中间段的不是那 20 个人。

## 五、🚨 合规边界(与 `合规红线.md` 同步)

行为证据要用**群体层面**的。**个体医生的处方行为明细不能当洞察证据**——无论它多有说服力。
同理,患者的个体数据(病历、随访记录、可识别的个人信息)不能进洞察材料。
需要"所做"类证据时,用聚合后的、不可回溯到个人的口径。
