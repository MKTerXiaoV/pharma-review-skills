# 穿透力三段 + 反证卡

> 招牌刀二。洞察是一整套动作,不是其中一个动作。只完成一段,不叫洞察。
> 归筐为「洞察」的条目,必须走完这三段;缺任一段,降级回「现象」。

## 三段

| 段 | 问什么 | 查什么 | 不合格的样子 |
|---|---|---|---|
| **一 · 表面现象** | 看到了什么 | 有没有具体行为:开了什么、没开什么、换成了什么、在哪一步停下 | 只有态度词、趋势词、人口标签("年轻医生越来越……") |
| **二 · 深层动机** | 为什么 | 动力排序、顾虑、地盘与专业壁垒、面子与角色、路径成本、谁替谁做决定 | 套话("观念不到位""认知不足");或把品牌想要的说成医生想要的 |
| **三 · 后果推演** | 一直这样会怎样 | 对品牌的具体损失:可替代性、治疗壁垒、DOT、份额、进院后的爬坡 | 没有;或只说"会有影响"这种不落地的话 |

**第二段是分水岭。** 大部分坏洞察死在这里——它们把第一段说得很细,然后直接跳到结论。

**第三段的边界:后果是"我们会失去什么",不是"我们该做什么"。** 写到"所以要去攻 X / 该把资源挪到 Y"就越到策略去了——那是 BP 策略体检的地盘。体检时看到材料里后果段里夹着动作,把动作那半句挑出来标"策略结论,不在本尺",不评好坏。

### 第二段的追问方向(挑用,不必全问)
- 这个治疗在他的**处方排序**里排第几?排在前面的是什么?为什么排在前面?
- 他不治/晚治/换掉,**对他自己**意味着什么?(时间、风险、麻烦、专业身份)
- 这件事在**门诊**和在**病房**是不是两回事?(时间、关系、患者心态完全不同)
- 中间是不是还有**别人**在做决定?(患者、家属、上级医生、药师、支付)
- 医学上成立的事,在真实门诊的**行为成本**上成立吗?

### 第三段的追问方向
- 如果这个状态维持两年,我们会失去什么具体的东西?
- 竞品会因此得到什么?
- 我们现在花的哪笔钱,会因为这条而白花?

## 反证卡三行(纪律抓手,不许省)

每一条判为「洞察」的,必须写满:

```
表面解释是:____
它解释不了:____（必须引材料里的具体事实/原话）
什么证据会推翻它:____
```

**规则**:
1. 第二行写不出来 = 这条不是洞察,是现象换了个说法。直接降级,不许放行。
2. 第二行必须**引原文**——指到材料里的哪句话、哪个数字。写"没有解释清楚"不算。
3. 第三行是可证伪性,同时是"你该去补什么证据"的最小动作。写不出来说明这条根本不可检验,降级成待验证假设。

### 反证卡示例(虚构)
```
表面解释是:基层医生对这个方案不熟悉,所以用得少。
它解释不了:材料里写"同一批医生在进修回来后三个月内用量上来了,半年后又掉回去"
           ——如果是不熟悉,学过之后不该掉回去。
什么证据会推翻它:调出这批医生半年后的处方明细,若掉量集中在特定患者类型
           而非全面回落,则"不熟悉"仍可能成立,本条需重写。
```

## 一个容易被跳过的检查

材料里同一个动机,换了三种说法写成三条洞察 → **算一条**。
判据:把三条的第二段(深层动机)并排放,如果指向同一个原因,合并。不许用换词凑条数。
