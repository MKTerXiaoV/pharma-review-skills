# 迭代法 · 让洞察体检越用越像你

> 体检系列通用的自我进化回路。几轮之后,它挑刺越来越像你这个专家 = 别人抄不走的私域护城河。

## 回路(四步)
1. **体检真实材料**:拿一份你手头真实的洞察材料(自己写的、下属交的、agency 交的、AI 生成的)让它体检。
2. **你亲手改满意**:它挑的你不认同的、漏挑的、归筐归错的——你自己改到满意。
3. **让 AI 提炼"你改了什么 + 背后规则"**:把你的修改喂回去,让它归纳成规则。
4. **写进 EXTEND / references**:规则沉淀下来,下次自动带上。

## 这个 skill 特别值得攒的规则

- **你所在治疗领域的"高频假洞察"**:妇瘤/肿瘤/慢病各有自己的套话。把你一眼就烦的那几句攒起来,它下次直接拦。
- **你认的证据门槛**:什么情况下你会接受"所说"类证据(比如某位你信得过的研究者的一手观察),什么情况你一律要看处方行为。
- **你们公司的合规惯例**:哪些表述你们法务一定卡、哪些是行业常态不必大惊小怪。
- **你判过的真判例**:哪条洞察你当时放行了、后来被打脸;哪条你毙了、后来证明是对的。**真判例比任何规则都值钱。**

## 注意
- **脱敏后再喂**:攒规则时去掉真实产品/公司/内部信息。
- 规则 ≤10 条,长了让 AI 归纳合并(防打架)。
- 攒的是"真实会溜过去的坏样子",不是稻草人——越真实越有用。
- **加任何正向判据时,顺手问一句:它会不会给某类雷发通行证?** 这是体检系列吃过亏的地方——新加的正向判据让模型把真雷当成了亮点。加完必须回跑 T2。
