# 评审团协议(深档增强 · 显式点名才启动)

> 「评审团」= 把体检从"一个 AI 过一遍"升级成"**多位各守一个透镜的评委盲审 → 反驳者逐条对抗验证 → 主笔合成**"。
> 独立性是它的全部价值:评委互相看不见,反驳者只负责推翻。

## 何时用(闸门 · 先过这关)
- 只在用户**显式点名**(说"上评审团 / 评审团体检 / 多专家会诊")时启动,**绝不默认触发**。
- 启动前必告知成本:数十个子代理,约为标准档的 **30–50 倍**;只值得用在**真要进 BP、进品牌故事、上评审**的洞察段,日常判一两句话用速检/标准档足够。**按实际执行层级如实告知**——降级跑"多轮自审"时消耗远低于满配。
- **🚦 子代理硬上限**:单次评审团**总子代理数 ≤ 40**。评委席是固定编制(5 位 + 评审席),不受此限;**唯一会膨胀的是反驳席**(挑刺条数 × 反驳者数),按此阶梯收敛,够用就停:
  1. 条数 × 4 ≤ 30 → 照常每条 4 位反驳者
  2. 超出 → 每条降到 2 位(**必留"行业惯例校准"**)
  3. 仍超出 → 按严重度排序,只有"高/中"进反驳席;"低"直接输出并标注「未经对抗验证」
  报成本时**报实际派出数**,不报区间估值。模型自身倾向于多派子代理,这条是硬闸,不是建议。
- **确认规则**:点名且材料已给全 = 视为确认,报一句成本即开跑;点名但没给材料 → 先走首次引导收材料。

## 三级执行(按环境能力择一 · 诚实告知用户跑的是哪级)
1. **评审团**(首选):环境有多智能体编排工具 → 评委并行盲审 → 合并去重 → 反驳者逐条投票 → 主笔合成。
2. **并行子审**:只有并行子代理 → 每位评委/反驳者一个独立子代理;反驳者可从 4 位减到 2 位(**必留"行业惯例校准"**)。
3. **多轮自审**(兜底):单对话 → 逐透镜轮流批判 → 反驳轮 → 合成。**必须明说:单机版,独立性弱一档。** 反驳轮可精简到 2 位(必留行业惯例校准);每轮重新读判据文件、禁止引用前轮条目编号。

## 评委席(盲审 · 5 位 + 评审席)

| 评委 | 只看一件事 | 标准来源 |
|---|---|---|
| 归筐 | 每条到底是现象/常识/金句/洞察?有没有把现象当洞察垫在底下? | `四筐归位判据.md` |
| 穿透力 | 三段齐不齐?第二段(深层动机)是真动机还是套话?反证卡第二行写得出来吗? | `穿透力三段.md` |
| 证据角色 | 支撑是"所做"还是"所说"?在什么场合拿到的?有没有把会议发言当行为证据? | `信源角色与信任梯度.md` |
| 伪洞察猎手 | 九条黑名单逐条扫,尤其套路化障碍与策略倒装 | `伪洞察黑名单.md` |
| 生意闸门 | 这条改变了哪个具体生意动作?指不出的逐条降级。**只问指不指得出,不评策略好坏** | SKILL.md 体检流程第 5 步 |

**⚠️ 一票否决标记**:任何评委发现 `合规红线.md` 的五条之一,标注【一票否决】——核实原文属实即保留,最终评级直接"不可用",不参与合议。

**评审席**(独立运行,不参与挑刺):扮演审这份 BP / 品牌故事的上级 + MA/RA,给出当场会顶回去的 **3 个最狠问题**(核心:"凭什么这么判?医生是真这么做还是这么说的?这条改变了我们哪个动作?"),必须具体到这份材料。

每位评委规则:
- 只从自己的透镜挑刺,**1–4 条最狠的,宁缺毋滥**;每条必引材料原文。
- 每条给:归筐结论或命中的失败信号 → 为什么这条撑不住 → 严重度(高/中/低) → 可落地的改法(删/降级待验证/补哪类证据/拆开重写)。
- 各自独立给评级 + 一句话理由。评委之间互相看不见。

## 合并去重
指向同一条洞察的挑刺合并成一条(保留最狠表述 + 最好的改法),记录"哪些评委命中"。不丢不增。
**同一个动机的不同措辞被写成多条洞察时,合并为一条**并在纪要里注明。

## 反驳席(对抗验证 · 每条合并后挑刺过 4 位反驳者)

| 反驳者 | 攻击角度 |
|---|---|
| 材料使用者视角 | 这条挑刺影响"这份洞察能不能往下推"吗?还是评委在秀深刻、实际不挡使用? |
| 一线老手 | 跑过多年市场的老手:真问题还是吹毛求疵?改法在调研可行性/时间上现实吗? |
| 方法论核查 | 有没有误用标准——**把跨品类也成立的真洞察当常识毙了**、把用户明标"待验证假设"的条目当成硬伤、拿"进 BP"的尺子卡内部速记?引用原文属实吗? |
| 行业惯例校准 | 这在真实医药市场实践里是不是**普遍且被接受**的做法?别把行业常态当硬伤(如内部讨论稿里洞察写得粗、用可及的二手调研先立假设)。一票否决类除外——该拦必须拦。 |

规则:尽力推翻,推翻不了才放行;模棱两可倾向推翻。**≥2 票推翻 = 毙掉**(进纪要);1 票反对 = 幸存+少数派意见附上。**【一票否决】类只核事实不票决**。

## 主笔合成(输出必须与标准档同构)
落 SKILL.md 统一输出模板(评级+四筐总账 → 🔴 → 🗣 → 🟢 → 🎯 → 🚫 九条)。评级合议:多数意见,平票取更保守一档;**存活的【一票否决】= 直接"不可用"**。

```
⚖️ 评审团纪要(追加段)
- 各评委评级 + 分歧点
- 每条挑刺:✓N/4 票幸存 · 提出者透镜 · 少数派意见(如有)
- 被毙挑刺 + 推翻理由(照实写,不藏)
- 评审席 3 问(并入 🗣 段)
```

诚实红线:0 条被毙也照实说,并提醒用户**人工复核 1–2 条**——洞察成不成立的最后一道校准永远在懂这个市场的人手里。
