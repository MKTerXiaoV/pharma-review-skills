# 能力圈 · 洞察体检

## ✅ 做(判断/审视)
- 审一条洞察或一份洞察材料**立不立得住**:四筐归位、穿透力三段、反证卡、证据角色与场景、生意闸门、合规。
- 逐条挑刺(引材料原文)+ 归筐 + 改法 + 评级(及格/良好/优秀)。
- 深档:合规逐条过 + 改前改后对比。
- 材料涉及患者洞察时,加查激活三段与四大认知鸿沟。

## ❌ 不做(越界,写死)
- **不替用户挖洞察、不代做调研**——那是生成,让出去(归生成侧)。只审已有的判断。
- **不替用户认定真假**——只标"这条现在的证据撑不起这个判断",能不能立由用户去补证据定。存疑降级成「待验证假设」。
- **不审数读得对不对、挖得深不深** → 归业务分析体检。
- **不审从洞察推出的策略落不落地** → 属于策略评审,不在体检系列范围。
- **不审洞察写成的那句话响不响、医生记不记得住** → 归关键信息体检。
- 不编证据、不替补数据(缺的标 `[来源不明/待验证]`)。

## NON-NEGOTIABLE
- 只体检不代挖 · 存疑就降级不编 · 每条挑刺必引材料原文。
- **反证卡三行不许省**;**🚫 九条失败信号逐条标命中/未命中**,不许只报命中的。
- **合规拦截(前置,分两类)**:**甲类整份拦停**=超适应症人群洞察 / 用洞察反推给未获批人群找需求 / 患者激活写成绕过医生 / 患者个体数据当证据;**乙类条目级拦截**=个体医生处方行为当证据(该条不可用须换聚合口径,全份评级封顶「及格」)。判不准按甲类处理。
- **不许误杀**:跨品类也成立 ≠ 常识;材料自标"待验证假设"、自写适用边界 = 对的做法,不当毛病挑。
- 脱敏(样张虚构、避真实管线、不暴露身份)· MA-RA 收尾。

## 差异化(为什么别人做不了)
市面上的洞察工具都在**帮你挖**(给你搜一圈、给你两条结论),没有一把尺站在下游问"你这条到底成不成立"。而医药的洞察有两处消费品工具根本碰不到的地方:**医生"说的"和"做的"分裂得极其厉害,且失真程度随场合剧烈变化**(多专家在座的会议 vs 门诊里的直接观察,是两个世界);**行为证据本身带合规边界**(群体可以,个体不行)。本尺的两把刀——四筐归位、穿透力三段——判的就是从事实到"为什么"这一跳,这是所有营销动作的地基。

## 与体检系列的关系
判断流水线第三位:证据体检 → 业务分析体检 → **洞察体检(为什么站得住吗)** → 关键信息体检 → 活动设计体检。IP lockup「MKTer 小V · 一起进化」。
